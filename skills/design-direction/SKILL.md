# 设计方向访谈

复用已有信息，只问缺项。用选项、数值示例和推荐原因解释术语，允许“你推荐”。

第一组一次询问（已知项省略）：
1. 终端、画布和兼容宽度：桌面网页、移动网页、小程序、App。
2. 视觉风格：简洁商务、紧凑工具、活泼品牌、内容导向等，允许自由描述。
3. 字体及字号：指定或授权推荐；正文、标题、辅助文字层级。
4. 圆角：直角、小/中/大或具体 px。
5. 品牌主色、浅/深主题、有无既有规范。

仅在影响结果时补问：信息密度、组件高度、内容宽度、间距、图标插画、语言、无障碍或组件库。不为已能判断的细节反复问。

建议不是全局规定。例如中文工具界面可建议正文 14–16px、小圆角 4–8px、4/8px 间距节奏，移动端、适老和内容产品另判断。不默认所有产品同字体同风格。

形成具体规范并标用户指定/AI 推荐：family/fallback、weight、字号、行高、字间距，文本/背景/描边/主色/语义色，栅格、间距、组件尺寸、圆角、阴影和适用交互状态。字体须在浏览器与目标平台可用；缺失说明替代。

参考分析后合入 design-spec.md 和 tokens.json，交回主入口询问可选网站或截图。
