# 参考分析

这是 design-to-handoff 的内部阶段说明。需要用户输入时遵守[内置问答约定](../interactive-input.md)，沿用当前阶段、待答问题和已有答案。

用内置问答提供“跳过参考”“提供网站链接”，允许在自由输入区直接填写多个链接。截图或附件通过宿主附件入口提供，文本问答工具不能接收图片时不要求在其中上传。没有参考不强加参考站，不阻塞。

默认重点提取信息架构、页面骨架、排版层级、内容密度、导航和交互模式。参考站不是项目视觉基础的默认来源；除非用户明确要沿用，不自动采纳其主色、字体、圆角、品牌或组件皮肤。可记录这些观察用于说明和比较，实际取值留给下一阶段确定。

网站：用可用网页/浏览器工具读取，记录 URL、日期、视口、状态及访问范围。私有页面正常授权；不能访问则说明，可改给截图或跳过。可读 DOM 时测量布局、padding/gap、字体、行高、圆角、颜色与效果，数值仅代表当前视口状态。未加载字体不能按 CSS 首选名声称已渲染。

截图：查看原图，记录分辨率、裁剪、缩放线索。分析层级、栅格、密度、对齐、颜色与组件。字体名称、CSS 像素、字重、色值和间距推断均标估计，不把 OCR 和图片像素距离当原设计值。缺失区域、交互状态不编造成参考事实。

输出“类别（布局/交互/视觉）/特征/证据/实测或估计/采纳与否/本次应用”简表。提取规律，不复制无使用权的品牌、文案及素材。已确认产品约束和同站规范优先于普通参考偏好及 AI 推荐；用户明确改变既有全局规范时展示影响并按已授权范围处理，实质冲突问清。

记录结论，继续[全局设计基础问答](foundations.md)，不能直接跳到保存或页面生成。用户跳过参考时也进入基础阶段；用户已授权全部推荐时按该阶段补齐具体值。基础确定后才询问可选本地保存，再正式生成。
