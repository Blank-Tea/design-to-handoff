# 全局设计基础目录与推荐基线

与[基础问答阶段](stages/foundations.md)配合使用。先按需求、终端、目标人群及已有规范形成推荐；下表是覆盖目录，不是一屏问卷。目录按细项保证覆盖；问答按下表合并相近参数，不逐条发二十题。不同组分开询问，已知项省略；先问用户能决定的效果，具体 token 可由智能体补齐。

## 建议问答分组

| 组 / 问答主题 | 覆盖项 | 同一次问答可确定的相近参数 |
|---|---|---|
| G01 主题与配色 | F01–F03 | 浅/深模式、主色与强调色、底色/中性色方向；语义色及交互色按所选方案派生 |
| G02 字体与排版 | F04–F05 | 字体、字重、正文大小和行高、标题层级 |
| G03 布局与导航 | F06、F14 | 内容宽度、栅格与断点、顶栏/侧栏和小屏折叠方式 |
| G04 密度与间距 | F07–F08 | 紧凑/舒展、控件和表格行高、组件内外间距 |
| G05 形状与层次 | F09–F10 | 控件/卡片/弹窗圆角、边框与分隔、阴影与浮层层次 |
| G06 图标与素材 | F11–F12 | 图标风格、图片/插画风格及装饰使用范围 |
| G07 组件与反馈 | F13、F15 | 组件体系、按钮/表单约定、加载/空态/异常反馈 |
| G08 动效 | F16 | 动效强弱、过渡时长和方式；reduced-motion 按约定落实 |
| G09 可访问性 | F17 | 目标人群特殊需求和可访问性目标；通用基线可直接采用已授权推荐 |
| G10 语言与内容 | F18 | 产品语言/地区、文案语气、日期/数字格式 |
| G11 数据可视化（按需） | F19 | 图表色板、图例和数值标注 |
| G12 特殊模式（按需） | F20 | 打印、触屏大屏、白标等本次适用的额外要求 |

前十组是建议组织方式，不是必须走完十轮；已有答案、继承和已授权推荐的组直接略过，后两组仅适用时开启。每组优先让用户决定 2–4 个关键偏好，派生状态和细粒度 token 自动补齐；内容过多、难以用同一方案表达时，再拆成该主题内的小组。不要为了压缩轮数把字体、动效、语言等无关维度塞进同一问答。用户明确要求更细时才逐项问。

## 覆盖目录

| ID / 维度 | 问题如何表达 | 必须落入规范的内容 |
|---|---|---|
| F01 主题与品牌气质 | 默认浅色、深色，还是都要？需要什么品牌感受？ | 默认模式、支持模式及切换/跟随系统规则；品牌关键词及应避免的特征；多品牌仅在需要时展开 |
| F02 主色与强调色 | 主操作和重点内容用什么颜色？ | 品牌主色、on-primary、hover/active、弱背景、focus；辅助强调色及用途；无品牌时给具体色值建议 |
| F03 中性色与语义色 | 整体底色更纯净还是柔和？成功/警告等有既定颜色吗？ | 页面/表面/浮层背景，主/次/弱/禁用文本，描边/分隔，link、success/warning/error/info 及对应文字/背景/图标；选中/禁用状态 |
| F04 字体家族与字重 | 字体偏中性易读还是更有品牌感？ | 正文/标题/数字/代码的 family、fallback、weight；中西文混排、字体可用性/许可及替代，不默认下载或购买 |
| F05 字号与阅读节奏 | 字号和阅读感希望紧凑、标准还是更大？ | display、h1–h3、正文、标签、辅助文字的 size/line-height/weight/letter-spacing；长文行长及数字对齐 |
| F06 画布、内容宽度与栅格 | 内容居中限宽还是铺满？主要适配哪些屏幕？ | 目标终端、代表视口、max-width、栅格列数/gutter/边距；断点及各段布局行为，侧栏/顶栏尺寸，缩放和最小宽度 |
| F07 信息密度与组件尺寸 | 一屏展示更多信息，还是更舒展易点？ | compact/comfortable 等密度，按钮/输入/表格行高、字号与内边距；视觉高度和可点击区域分开记录 |
| F08 间距与节奏 | 区块之间紧凑还是留白更多？ | 基础步长、spacing scale、页面/区块/卡片/表单间距以及内外边距；区分宏观留白与组件内部间距 |
| F09 圆角体系 | 更利落的小圆角，还是更柔和的大圆角？ | 控件/卡片/弹窗/浮层的 radius token；pill 仅用于哪些类型，不把所有元素统一成一个半径 |
| F10 边框、层次与阴影 | 用细边框还是阴影区分层次？ | border width/style/color、分隔线、阴影等级、遮罩透明度；浮层/z-index 层级规则，避免随意堆叠 |
| F11 图标系统 | 线性还是面性图标？ | 一套图标来源/风格、stroke、常用尺寸、颜色及文本对齐；图标按钮命名/提示和可点击区域，缺素材替代规则 |
| F12 图片、插画与装饰 | 页面需要什么图片风格和视觉装饰？ | 照片/插画/纯 UI 的使用范围、比例/裁切、色调、占位/失败图、渐变/纹理规则；品牌/素材来源及许可限制；无图也明确记录 |
| F13 通用组件与复用 | 有组件库要沿用吗？按钮、表单和卡片采用哪种体系？ | 技术/平台已定时复用组件库；按钮层级、尺寸/状态、输入/选择/表单标签与校验、卡片/表格/弹窗/提示的通用约定及组件引用；不强加技术选型 |
| F14 导航与页面骨架 | 导航希望顶部、侧栏还是其他形式？ | 顶栏/侧栏/底栏、面包屑、当前态、折叠/粘性、页面标题/工具区；沿用参考的哪些结构及小屏变化 |
| F15 反馈与交互状态 | 操作反馈更直接还是更克制？ | default/hover/active/focus/selected/disabled、loading/empty/error/success；表单错误、异步/提交/保存反馈、危险操作确认和键盘操作；按实际组件覆盖 |
| F16 动效与过渡 | 动效更克制还是更明显？ | duration、easing、进入/退出、hover/抽屉/弹窗规则；reduced-motion；复杂动画仅在确有需要时设计 |
| F17 可访问性 | 有适老、弱视或其他可访问性要求吗？ | 对比度目标、focus 可见性、键盘顺序、目标区域、非纯颜色表达、缩放/重排、读屏语义；基本目标默认提供，不让“跳过”变为取消易用性 |
| F18 语言与内容风格 | 面向哪些语言和地区，文案偏什么语气？ | 语言/地区、文案语气、大小写/标点、日期/数字/货币、长文本/缺失内容/脱敏规则；多语言与 RTL 仅适用时展开，不从用户聊天语言推定产品语言 |
| F19 数据可视化（条件项） | 图表需要怎样的配色和标注？ | 有图表时定义分类/连续/发散色、状态与系列色区别、单位/数值格式、图例/tooltip、色盲可辨和空/异常数据；无图表标不适用 |
| F20 跨端与特殊模式（条件项） | 是否有打印、触屏大屏、白标等额外模式？ | 仅按范围补充触屏/打印/高对比/白标等差异；模式 token 覆盖和继承关系。深色已在 F01 决定，不重复问 |

范围不同，F13–F15 的具体组件集合不同；没有表格就不额外设计表格，但通用状态不能遗漏。F06 确定所有约定终端的响应规则，F20 只补特殊模式。

## 如何选推荐方案

先继承同项目已确认规范，再用需求中的品牌资产和技术限制。新项目选适合其用途的基线：

- 内容/服务网站：优先阅读、导航和行动入口，正文通常 16px，舒展间距，限宽内容。
- 后台/效率工具：重视扫描、表单和数据密度，可推荐正文 14px、控件 32–36px；触屏入口仍扩展点击区域。
- 品牌/营销网站：标题、字号比例、留白、图片和品牌强调更突出；不要直接套后台尺寸。
- 移动/适老产品：按视口、触控与目标人群扩大字体和区域；不能把桌面画板等比缩小。

这些只是选择依据，不能把项目自动锁定为某一种。参考网站只提供已明确采纳的布局/交互线索；除非用户要求或项目已有规范，不直接继承其字体和色值。推荐必须具体，说明依据，并标为 recommendation。

## 可计算的起点：无既有品牌的标准服务网站

仅当需求匹配且用户选择推荐时使用；已有值优先。单位为 CSS px，设计画布用相同逻辑尺寸；目标工具有不同单位时记录映射。此处以浅色、简洁、阅读优先为例，不作为每个项目的统一外观。

| 类别 | 起点 |
|---|---|
| 颜色 | primary `#2563EB`，on-primary `#FFFFFF`，hover `#1D4ED8`，active `#1E40AF`，primary-subtle `#EFF6FF`；canvas `#F8FAFC`，surface `#FFFFFF`，overlay-surface `#FFFFFF`；text `#0F172A`，secondary `#475569`，muted `#64748B`，disabled `#94A3B8`；border `#CBD5E1`，divider `#E2E8F0`，control-border `#64748B`，focus `#2563EB` |
| 语义色 | success `#15803D` / bg `#F0FDF4`，warning `#92400E` / bg `#FFFBEB`，error `#B91C1C` / bg `#FEF2F2`，info `#1D4ED8` / bg `#EFF6FF`；各状态文字使用该深色、辅以图标和文字，不把浅色背景作文字 |
| 字体 | 产品是简体中文时可用 `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`；其他语言选择覆盖其字形的栈；正文 400/标题 600。未确认安装的字体只列 fallback，不声称已可用 |
| 排版 | display 40/48、h1 32/40、h2 24/32、h3 20/28、body 16/24、label 14/20、caption 12/18；前两数为字号/行高；字间距 0，长文 60–75 个拉丁字符或约 30–40 个汉字一行，小屏 display/h1 降到 32/40 与 28/36 |
| 布局 | 代表视口 1440、768、390；断点 640/1024；小于 640 为 4 列/边距 16，640–1023 为 8 列/边距 24，1024 起 12 列/边距 32；gutter 16/24/24，内容 max 1200；顶栏 64，小屏 56；侧栏仅需要时使用，建议 240；320 宽做重排检查 |
| 密度与间距 | comfortable；控件高度 sm/md/lg 32/40/48，默认 40；触控目标至少 44×44；表格如需要默认行高 48；间距 0/2/4/8/12/16/24/32/48/64/96，基础 4；控件横向 padding 16、卡片 padding 24/小屏16、区块间距 48/小屏32 |
| 形状与层次 | radius control 8/card 12/dialog 16/pill 9999（仅标签/胶囊）；边框 1；shadow sm `0 1px 2px #0F172A0D`、md `0 4px 12px #0F172A1A`、lg `0 12px 32px #0F172A26`；遮罩 `#0F172A66`；层级 base 0/sticky 100/dropdown 200/modal 300/toast 400 |
| 图标与素材 | 统一线性矢量图标，16/20/24、stroke 1.5–2（选定图标集后固定）；无内容图片需求时不添加装饰插画；需要图片时定义比例与 object-fit，来源单独记录 |
| 状态 | 主按钮为 primary + on-primary，hover/active 用对应值；focus outline 2px/offset 2px；禁用使用独立文本/背景，不降低整组透明度来假定满足对比；loading 保持尺寸并阻止重复提交；empty 给原因和下一步，error 给具体恢复动作 |
| 动效与可访问性 | fast/normal/slow 120/200/300ms，easing `cubic-bezier(0.2, 0, 0, 1)`；reduced-motion 去非必要位移；目标 WCAG 2.2 AA：普通文字 4.5:1、大字 3:1、必要非文字 UI 3:1，可见焦点和键盘访问，不能只靠颜色表达 |
| 内容与导航 | 产品语言、语气和地区按需求决定；没有规定时推荐简洁直接的操作文案，并标明待确认的语言假设；导航结构依据业务及参考选择，不固定为某一种站点模板 |

对比度目标是检查要求，不能把表中配色视为全组合已达标。按实际文字/背景、边框用途、字号/字重和透明度逐项核对，分隔装饰线不等于交互控件边界；记录实测或待验证。支持深色时为每个语义角色提供深色值并检查，不直接反色，不把未设计的深色模式列为已支持。

品牌色变化时派生状态色并重新检查。字号变化时重算行高、控件高度、表格密度；圆角按尺寸层级分配。用户选择推荐后，应把完整结果写成项目自己的值，而不是在文档中仅引用这张示例表。
