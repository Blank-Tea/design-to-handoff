# 需求到分层设计交付

## 使用方式

顺序读取并执行下列子 skill，不需要新聊天或并发代理。所有 skill 保持同级目录关系，不能只复制主入口。独立使用子 skill 时只询问自身必需且缺失的输入。

交付对象为含真实文字、容器、矢量和内容图片图层的在线设计文件。整页 PNG、PDF、画在图片上的红线、Code/Make 运行预览都不能代替分层文件。代码标注是元素样式片段，不是完整业务代码。

## 提问节奏

每阶段合并问题，等待回答再执行依赖步骤；复用已知信息，不一口气索取全部问卷。用户说“你推荐”时采用并说明建议；可选项提供“跳过”。必要回答缺失保持等待，不能把超时当成同意。

第一次问：
> 请提供【需求文档】和【补充文档】的文件地址、目录或在线链接。补充文档可回答“无”。目录有多个候选版本时，我会列出供你选择。

不将技能创建者在其他聊天中的业务、语言和设计偏好视为本次需求。

## 按顺序执行

| 阶段 | 读取并执行 | 完成条件 |
|---|---|---|
| 1 需求 | [design-intake](../design-intake/SKILL.md) | 展示浓缩需求、来源和重要未决问题 |
| 2 方向 | [design-direction](../design-direction/SKILL.md) | 必要设计方向已回答或授权推荐 |
| 3 参考 | [design-reference-analysis](../design-reference-analysis/SKILL.md) | 已分析参考或明确跳过 |
| 4 保存选择 | 本入口下文 | 知道是否保留本地交付副本 |
| 5 设计 | [design-compose](../design-compose/SKILL.md) | 正式文档、预览和需求覆盖已核对 |
| 6 平台选择 | 本入口下文 | 选择 Figma、Penpot、两者或暂不上传 |
| 7 平台交付 | [Figma](../design-publish-figma/SKILL.md) / [Penpot](../design-publish-penpot/SKILL.md) | 分别记录上传、图层与查看者检查结果 |

摘要展示后直接问设计方向，允许用户同时纠正摘要，不为每个已明确步骤增加确认。先问清改变主要流程、权限或页面的冲突。

## 可选本地保存

参考分析之后、生成之前问：
> 是否保留本地设计文件？请提供目录，或选“不保留本地副本”。默认包含设计文档、规范、HTML/CSS、预览和交付记录。

不指定目录表示不保留本地交付副本，不自动保存到桌面。允许在许可的临时目录渲染、转换、检查；成功后只清理本次创建且不再需要的临时文件。上传受阻且没有副本时，说明临时文件仍在，询问保留位置或改选平台，避免丢失。不要承诺删除宿主聊天、系统缓存和平台云文件。

指定目录后创建项目子目录，不覆盖同名文件；权限不足使用宿主审批机制。原生 .fig / .penpot 只有真正导出成功才列入交付，不重命名其他格式冒充。

## 平台与权限

可提前只读发现工具并告知未连接，但保持“先设计、后选上传”顺序，不提前创建云文件或要求同时授权两平台。

完成设计后问：
> 上传到哪个平台？【Figma】【Penpot】【两者】【暂不上传】。优先免费能力；能列出可写项目时展示列表，不能时可给目标文件/项目链接，或使用可用的个人草稿/当前文件。

菜单中说明各平台具体默认落点。用户选择即授权上传本次设计至该落点，不重复请求相同许可。明确目标优先；目标不明、当前文件不符或变更已有分享范围时先问清。免费受阻不自动购买、升级、调用收费生成或转传另一平台。

复用已有连接，未连接使用宿主授权界面或平台子 skill 初始化说明。技能文本不能产生 OAuth 弹窗、安装工具或创造接口能力。密码、Cookie、令牌及含密钥的 MCP URL 不写入聊天输出、设计文件和交付记录。

默认沿用文件权限或向用户明确指定的账号开放查看。公开链接和扩大分享范围先让用户选择；不通过邮件/聊天工具发送消息。原始需求文档不默认上传，远端只放派生设计与必要说明。

## 状态与完成

按[会话记录约定](references/session-contract.md)维护信息，可在会话内；未选保存不写持久检查点。需求变更仅重做受影响阶段。两平台共用一版需求、规范和 viewId。

记录每次云写入返回的文件/节点 ID。部分失败先读回再续写，修正根因后最多重试两次；仍失败保留具体阻塞和继续点，不盲目制造重复文件。

分别报告：仅本地完成、已上传但标注待验收、本人检查通过但多人查看待验收、多人标注交付验收通过。给出真实链接、覆盖页面及缺项。没有第二账号验证，不声称多人查看已实测。

本包是两套交付方案，不表示当前账号已接通。执行时以真实工具契约、宿主技能约束和官方权益为准。
